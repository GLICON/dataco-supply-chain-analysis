# DataCo Supply Chain Analytics

Supply chain analysis of 180K DataCo order items (2015-2018): diagnosing late deliveries,
discount-driven margin loss and suspected fraud, with SQL, Python, Excel and Power BI.

## Status
Work in progress.

## Data
Download DataCoSupplyChainDataset.csv from Kaggle
(https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)
and place it in data/raw/.

## Setup
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
